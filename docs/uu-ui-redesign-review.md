# UU 远程风格客户端：整体 UI/UX 评审与改造方案（待评审）

日期：2026-11-26
范围：`flutter/lib/custom_ui/`（custom-ui 开启后的全部自绘界面），以及被它替换、遮挡、隐藏的 stock 页面与弹层
参考：UU 远程官网/帮助中心功能清单、你提供的 UU 客户端截图、ToDesk 官网交互说明、Material 3 与 Apple HIG 通用规范

> 说明：网上能抓到的 UU 官方页面以功能清单为主，没有客户端界面截图；视觉方向以下面「设计方向」为准，具体细节可按你给的截图再对齐。以下编号用于评审，回复「做 A1–A3、B1、跳过 C4」这种即可。

## 一、设计方向

关键词：**干净、克制、留白、层级清晰、深浅分离**（首页浅色、会话深色）。

| 项目 | 规范 |
| --- | --- |
| 主色 | 蓝 `#2563EB`（信任感、与 RustDesk 生态一致；将来换品牌色只改 token） |
| 辅助色 | 在线绿 `#22C55E`、警告橙 `#F59E0B`、危险红 `#EF4444` |
| 中性色 | 文字 `#111827` / `#6B7280`，页面底 `#F5F6F8`，卡片白，描边 `#E5E7EB` |
| 会话深色 | 顶栏 `#16161A`，面板 `#2C2C2E`，卡片 `#3A3A3C`，主文字 `#F2F2F7` |
| 字号 | 28 / 22 / 18 / 16 / 14 / 12；正文不小于 12，深色栏由 11 提到 12 |
| 间距 | 4 的倍数；页面 24（桌面）/ 16（手机）；卡片内边距 16 |
| 圆角 | 8 / 12 / 16 / 20 / 999（胶囊） |
| 阴影 | 只保留一个柔和卡片阴影，不用多层重阴影 |
| 动效 | hover/press 150ms，面板 250ms，页面切换 200ms，ease-out |
| 图标 | 单一图标体系（Material Symbols Rounded）；平台图标统一一个组件，用系统图标模拟，不使用品牌 logo 素材 |

**主线原则**：所有颜色/字号/圆角先进 token；新组件先在 `custom_ui/widgets/` 落地；`custom-ui` 关闭时仍走原 stock 路径（AGENTS.md 约定）。

## 二、现状盘点

| 区域 | 现有实现 | 主要问题 |
| --- | --- | --- |
| 桌面主窗口 | 侧栏（24.3% 宽，240–400px）+ 52px 顶栏 + 240px Hero + 动作条 + “快速启动”空卡；默认 920×680，最小 760×560 | 单设备展示导向，设备多时效率低；“快速启动”是空占位；无搜索；顶栏图标偏多；字号偏小 |
| 桌面远控窗口 | 44px 深色顶栏：会话标签、`+`、“控制中”菜单、窗口按钮；stock 浮动工具栏默认隐藏 | 菜单只覆盖切屏/画质/缩放/退出；声音、全屏、聊天、文件传输、隐私屏等入口被隐藏；无质量指示；无退出确认 |
| 手机首页 | 3 个 tab（我的设备/远程协助/我的）；96px 设备卡，渐变缩略图 + 壁纸；在线/离线折叠分组 | 平台图标重复出现两次；长按连接不可发现；无搜索/添加入口；卡片缺“上次连接”等信息 |
| 手机设备详情 | 头部 + Hero + 操作行 + 信息行 | 与首页视觉不完全一致，信息组织可再压缩 |
| 手机远控会话 | 全屏画面 + 60px 深色底栏（展开窗口/显示桌面/触控模式/键盘/操作）+ 深色操作面板 | 没有顶部状态栏：设备名、返回、延迟、显示器切换都不在画面上；功能入口分散在底栏+面板 |
| 设置 | 手机自绘设置页；桌面自绘 icon-tab 弹框 + stock 设置内容；高级设置跳 stock 页 | 两套视觉；stock 内容与自绘外壳割裂；字号/间距未统一 |
| 登录/账号 | 手机整页登录、桌面弹框登录；顶栏账号 chip / 我的 tab / 设置账号卡三处入口 | 两套实现与视觉；入口行为不完全一致 |
| 反馈 | stock BotToast + stock AlertDialog（如“通知”弹框、退出确认）+ 少量自绘 | 风格混杂，是“看起来不像一个产品”的最大来源之一 |

**已发现的重复与死代码**：平台图标有 4 套逻辑（手机 `_brandIcon`、桌面 `_peerPlatformIcon/_localPlatformIcon`、远控顶栏 `_platformIcon`、`widgets/uu_platform_icon.dart`，最后一套只被未引用的 `uu_device_card.dart` 使用）；两套绿色（`#22C55E` / `#16A34A`）、三套蓝色（`#2563EB` / `#2F6BFF` / `#3B6BF6`）；`uu_home_page.dart` 的 `_buildPermissionBanner` 未被引用。

## 三、影响最大的 10 个问题

1. **没有设计系统**：颜色、字号、圆角、间距散落在各文件，手机端和电脑端灰底、绿色、蓝色都已经不一致。
2. **stock 弹层混入自定义流程**：密码框、连接中、退出确认、通知弹框、toast 都还是 RustDesk 默认样式。
3. **会话功能可达性下降**：新的深色顶栏默认隐藏了 stock 浮动工具栏，但“控制中”菜单没补齐声音/全屏/聊天/文件传输/隐私屏。
4. **手机远控没有顶部状态栏**：看不到设备名、延迟、返回和显示器，退出只能进“操作”里找。
5. **手机设备卡交互反直觉**：长按卡片直接连接，没有任何视觉提示。
6. **桌面首页是“单设备海报”**：快速启动是空占位，找设备只能靠侧栏，设备一多就低效。
7. **字号与触控目标偏小**：深色栏 11px、部分按钮 12px；手机部分图标点击区不足 44px。
8. **平台图标/状态色不统一**：同一台 Mac 在不同页面分别是苹果、笔记本、“电脑”图标。
9. **设置、登录、账号三处各有一套**：手机与桌面各写一遍，后续维护成本高。
10. **空状态、错误态、加载态缺失**：断网、设备为空、无最近连接时页面显得“没做完”。

## 七、风险与约束

- **回归面**：stock 弹层与页面在共享代码里，替换时必须保留 `custom-ui` 关闭时的原路径（AGENTS.md 要求）。
- **Flutter 3.24.5**：提交的 Flutter 源码必须保持 3.24.5 兼容；本地验证用 3.44.9 + 现有补丁脚本。
- **移动端会话顶部栏**：要避开 iOS 安全区、小窗/PiP 与横屏；自动隐藏逻辑不要和按键映射层抢触摸。
- **深色模式**：需要全部 token 化，单独一期，不建议夹在页面改造里。
- **平台图标**：用系统图标模拟，不引入品牌 logo 素材（版权/商标），Apple/Windows 标志只在必要处使用。
- **功能边界**：移动端会话内文件传输受单会话限制，仍只从设备详情进入；不新增排除项。
